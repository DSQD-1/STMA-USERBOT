# STMA USERBOT

STMA — Telegram Business automation system.

## Features

- Telegram Business Connections
- New Business messages
- Edited Business messages
- Deleted Business messages
- `.help`
- `.info`
- `.uinfo`
- `.ruinfo`
- `.t`

## Stack

- Node.js
- Express
- Telegram Bot API
- Turso / libSQL
- Render
